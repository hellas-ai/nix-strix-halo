`0004-bootstrap-retry-nonblocking.patch` follows 0003 and preserves the socket constructor's contract when a retry recreates the descriptor. Socket creation failure raises its existing SysError form. With an asynchronous or abortable socket, F_GETFL reads the new descriptor's flags and F_SETFL adds O_NONBLOCK without replacing other flags; either fcntl failure raises the corresponding constructor-equivalent SysError. A synchronous socket with no abort flag keeps its existing blocking behavior.

Run `python3 -B pkgs/mscclpp/tests/socket-retry-cpu.py`. Nine paired cases compile the actual before/after pollConnect method with the pinned Socket declaration and host exceptions. All socket, poll, getsockopt, sleep and fcntl calls are CPU surrogates. The cases qualify asynchronous and abortable flag preservation, synchronous behavior, zero flags, creation/F_GETFL/F_SETFL failures, successful completion and fatal nonretryable error. Both executables link only standard host libraries. The historical 0003 test/source/receipt and failed live arms remain unchanged. Complete bootstrap, real reconnect timing, GPU/RDMA and package qualification remain pending root-owned execution.

Root integration should append 0003 then 0004 after the independent 0002 traffic-class patch. This source-only commit does not edit the shared Nix patch list, build a package or run a fleet action. The initiating asynchronous error in the preserved arm remains unassigned.
