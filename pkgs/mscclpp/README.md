This package adds `MSCCLPP_IB_TC` to MSCCL++ v0.9.0. Unset means0, preserving upstream behavior. Set a decimal byte from0 through255 before the first `env()` access. Leading zeroes are accepted. Empty values, signs, whitespace, suffixes, hex notation and overflow raise `mscclpp::Error` with `ErrorCode::InvalidUsage`; nothing is silently truncated.

The value is stored as unsigned `Env::ibTrafficClass` and assigned to `qp_attr.ah_attr.grh.traffic_class` during the existing QP RTR transition when the path uses GRH. `MSCCLPP_IB_TC=106` encodes DSCP26 and ECN2. A serving unit can later choose `config.sconfig.roceQos.dscp * 4 + 2`; this patch does not set any unit environment. The service level remains0, and this source change alone does not prove host/switch classification or performance.

The C ABI, EndpointConfig and collective arithmetic are unchanged. Adding a public Env field changes the C++ class ABI: rebuild C++ consumers together with this library. Like the existing environment fields, the value is captured once; changing the environment after initialization does not retag existing connections.

`python3 pkgs/mscclpp/tests/check-ib-traffic-class.py` applies the first two package patches without fuzz to the pinned source and compiles a tiny host-only translation unit containing actual patched `env.cpp` and upstream generic Error methods. Only the logger macro and export annotation are stubbed; this test does not initialize GPU/RDMA or build the complete package. It checks unset0, all256 byte values, four leading-zero cases,28 malformed/out-of-range cases, and nine actual Env-constructor cases. [The saved CPU receipt](tests/ib-traffic-class-cpu.json) binds source/patch/test hashes.

The package also carries the independently qualified [POLLERR connect fix](tests/socket-pollerr.md) and [nonblocking retry fix](tests/socket-retry.md). The [full Nix package build receipt](../../lib/bench/results/glm53-mscclpp-nix-package-build-v1.json) records all four applied patches and the compiled library. Its GPU architecture probe is explicitly bypassed. Rebuilt consumers, native bootstrap and live traffic classification require their own qualification; this build establishes no throughput gain.
